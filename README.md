# Darman waitlist

Landing page for the Darman demand test: genuine US over-the-counter medicine, ordered from abroad and picked up by family in Afghanistan.

- Page: `index.html` (English, Dari, Pashto; switch with `?lang=fa` or `?lang=ps`)
- Track ads by adding `?src=instagram` (or `utm_source` / `utm_campaign`) to the link
- Signups are saved to the `waitlist` table in the Supabase project `pharmacy-waitlist`. The page's public key can only add rows, never read them.
